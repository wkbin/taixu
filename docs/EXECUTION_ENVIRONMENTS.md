# 执行环境与会话资源作用域

## 能力边界

`runtime/environment/ExecutionEnvironment` 是文件与进程的统一替换入口。一个环境包含不可变的 backend、distribution、workspace、owner 身份，以及文件读写/编辑、命令、协议子进程、PTY、后台进程和关闭接口。路径使用 guest 路径；远程实现不需要暴露手机的 `java.io.File` 或 Android 启动参数。

生产装配由 `LocalExecutionEnvironmentFactory` 完成。它校验文件工具的工作区根与 `LinuxRuntime.workspacePath()` 相同，拒绝越界工作区映射，并在创建时固定发行版。相对文件路径和未显式指定 cwd 的命令都基于同一个工作区；未关联项目的工具环境使用 `/workspace`。命令仍可显式指定其他 guest cwd，文件工具仍受原有工作区访问边界约束。

`SessionExecutionEnvironments` 按会话缓存环境。切换前台会话不会改变后台会话的环境；同一会话不能静默改绑工作区。子任务拥有独立资源作用域和进程命名空间，继承父环境的 backend、distribution 和 workspace。工具调用仍使用父 sessionId 检查权限、记录消息和捕获文件快照，资源归属不作为权限豁免。

后台进程的模型可见 ID 不变，底层 ID 使用环境独有命名空间。同名进程在不同会话/子任务间互不干扰；status、logs、list、stop 只能访问当前环境拥有的进程。普通轮次结束保留会话的后台服务；子任务结束、会话删除或显式 process(stop) 会关闭相应资源。

## 消费者与迁移约束

| 消费者 | 当前路径 |
| --- | --- |
| read / write / edit | 当前环境的 `files`，快照通过同一文件接口读取 |
| base / process | 当前环境的命令及后台进程接口 |
| MCP STDIO | 协程上下文携带当前环境，通过 `openSession` 拉起协议进程 |
| MCP 连接缓存 | 按 server + 执行环境身份隔离；删除会话关闭其连接，服务失效关闭该服务全部环境连接 |
| 交互式 PTY | `openTerminal` 返回支持 input/resize/interrupt/close 的 `LinuxSession` |
| Android Termux 终端页面 | 通过环境工厂选择后端；仅接受显式的 `LocalTerminalLaunch` 适配器 |
| 下载 | 当前环境的 `downloads`；只传 guest 路径，后端负责 HTTPS、续传、配额、校验和图片检查。缺少下载能力时明确拒绝 |
| 完整输出保存 | 当前环境的 `artifacts`；先脱敏，再执行保留期和配额检查。缺少产物能力或保存失败时仅截断 |
| rewind / undo | 当前环境的 `files`，通过同一接口检查外部修改、恢复、删除和撤销；不要求本地文件类 |
| build_script 模板管理 | 共用应用脚本库；list/get/create/update/delete 不依赖手机当前发行版，修改操作仍走审批 |
| build_script 项目挂载 | 当前环境的 `buildBindings`；缺少适配器时拒绝 bind/unbind，远端同名项目不能修改手机绑定 |
| 子任务 / 双智能体编排 | 工具调用按操作归属绑定父环境，汇总通过父环境的文件/产物接口保存；不再要求手机当前发行版兼容 |
| Android/Flutter 工程构建管线 | `WorkspaceBuildRunner` 仍依赖本地 SDK/RootFS 和工程模型；尚未提供远程工程构建实现 |
| 已知环境值脱敏 | 当前环境的 `outputSecrets`；本地实现按绑定发行版读取，远端处理不刷新手机环境变量 |

HTTP MCP 是用户配置的外部服务，其 HTTP 连接继续由全局 MCP 管理器管理，不随某个会话删除关闭其他会话共用的连接。

尚未改用环境接口的本地服务也受 `boundLocalDistribution` 保护：在已绑定的工具调用中，LinuxRuntimeImpl 的命令、子进程和终端启动读取绑定发行版，拒绝显式跨发行版或远程上下文调用本地运行时。这样即使全局发行版在兼容性检查后改变，也不会切换到另一执行世界。

这次提供了统一接口、本地实现和假远程后端的替换验证。下载、完整输出保存、代码恢复、子任务编排和项目脚本挂载的消费者已支持远程接口；本地文件和下载器封装在 `LocalExecutionDownloads` / `LocalExecutionArtifacts` 内。`build_script` 管理模板及挂载，不会启动构建；脚本库为应用共享，绑定由各后端保存，远程后端需要按真实主机/工作区隔离，并在执行时解析有效模板 ID。尚未实现真实 SSH 连接、远程终端页面渲染及远程工程构建管线。后续接入远程 Linux 时应实现整个环境工厂及其能力接口；缺少适配器时继续明确失败。当前没有 LSP 消费者，新增 LSP 时应通过 `openSession` 使用同一个环境。

`ExecutionArtifacts.storageKey` 必须标识真实存储位置：同一远端/工作区的不同会话共用锁，不同主机必须使用不同 key。列表必须完整，目录不存在返回空列表，连接或读取失败返回失败。保留 7 天、最多 256 个输出和 64 MiB 总量；单个产物最多 16 MiB。枚举失败或删除旧文件失败导致配额不足时拒绝新增。保存通过临时文件替换目标，不使用覆盖拷贝写入半份产物。源代码管理排除由后端处理，失败不影响已有输出读取。

`SubagentSummaryPublisher` 在保存前按工具输出相同的规则脱敏，包括当前环境的已知值和隐私设置。完整报告优先通过 `artifacts` 保存，复用输出配额和保留期；缺少产物能力时可通过同一环境的文件接口保存小报告，写入失败时仍截断。取消会传播，不会伪装成保存失败继续注入。`LinuxEnvironmentManager.redactionSecrets` 在同一锁内读取绑定发行版并复制值；刷新失败不返回其他发行版的缓存，下一次访问会重新读取。

## 生命周期契约

`harness:core/SessionResourceScope` 保持纯 Kotlin：

1. 关闭作用域时先拒绝新活动和资源注册。
2. 取消全部在途活动，并等待其 finally 段排空；调用方取消也不能提前移除尚未排空的活动。
3. 按获取的逆序释放工具注册、监听器、连接和环境资源。
4. 某项清理失败仍继续清理其他资源，报告失败；重试只处理之前失败的清理项。
5. 重复/并发关闭不会重复释放成功清理的资源；在自己的活动内关闭自己会明确报错，避免自等待死锁。

`SessionResourceScope.create` 与 `SessionExecutionEnvironments.install` 为扩展创建提供失败回滚。`own` 注册清理回调；返回的 handle 仅用于资源已经被调用方释放之后撤销所有权。监听器、工具注册或后台任务不得脱离所属作用域长期运行。

会话删除先设置 tombstone 并取消/等待 Harness 主任务，再关闭环境作用域，最后移除会话投影、诊断、审批授权和持久化会话记录。子任务收尾先处理未结算工具，再释放子任务资源，然后提交 lane finish；清理失败保留恢复指针。终端创建失败关闭已创建的进程/环境，并恢复此前的终端记录。MCP 关闭会等待读泵结束。

扩展在初始化前即归属会话。初始化失败或取消会立即回滚；回滚失败时保留未释放部分，结束会话继续重试，已释放的监听器不会再次释放。子环境身份校验失败也保留回滚作用域，重新创建前必须先清理旧环境，父会话或子任务关闭同样可以重试。空 sessionId 的兼容调用按工作区持有环境，关闭该匿名会话会清理全部工作区并阻止重新创建；关闭失败不跳过其他工作区。

本地环境通过 `SessionResourceScope.acquire` 在启动子进程或后台进程前登记所有权。已关闭的作用域不会调用启动工厂；取消后迟到的结果先释放再退出，释放失败仍由作用域持有，关闭环境时继续重试。`OwnedResource` 将显式关闭与作用域清理串行化，成功后撤销清理注册；创建失败保留原始异常和回滚错误。

环境注册表只在登记绑定和检查关闭状态时持有全局锁，创建与失败回滚在各绑定自己的锁和资源作用域中完成。同一绑定的并发请求复用一次创建，其他会话或子任务不会被慢创建/慢回滚阻塞。创建前就登记环境清理回调，关闭会取消并等待正在创建的任务；后端迟到返回的环境也必须释放，不能进入工具执行。返回环境前再次检查绑定和关闭状态，防止已完成创建的结果在会话关闭后交出。

取消等候者不会取消其他调用发起的创建；发起者取消时先排空和释放其结果，等候者可以重新创建。正在创建的会话也已经固定工作区，不能趁创建未完成改绑。子任务首次触发的父环境仍归父会话所有，结束子任务会阻止随后的子环境创建；父环境由父会话结束时释放。

MCP 服务撤销与连接创建共用启动锁，避免撤销完成后仍留下正在创建的连接。撤销会尝试关闭所有环境连接并汇总错误。失败连接保留在传输层且标记不可复用，独立于会话的连接也可以再次撤销；重连必须先成功释放旧连接。连接和通道的关闭串行且成功后幂等，关闭失败可重试。

MCP 通道关闭先排空读泵，再分别尝试释放协议进程和独立环境，汇总全部失败；其中一项失败不会跳过另一项，重试只处理未成功的部分。读泵异常退出时成功关闭的进程也记入同一清理状态，随后关闭通道不会重复释放进程。

终端管理器在创建前登记资源所有权，关闭正在创建的终端时先取消并等待创建排空，迟到的环境不会发布为可用终端。进程、环境和持久化记录回滚分别跟踪清理结果；创建或关闭失败保留重试入口，成功释放的部分不会重复释放。批量关闭会尝试全部终端并汇总失败，关闭期间拒绝新建终端；并发关闭最后一个终端只创建一次默认终端，批量关闭不会触发默认终端重建。创建任务不能关闭自己或批量关闭包含自己的终端，避免等待自身。原生进程创建通过 `TerminalProcessFactory` 适配，页面继续使用本地 Termux 渲染器。

多个资源释放失败以 `ResourceCleanupException` 保留失败列表、首个原因和其余 suppressed 错误，避免协程堆栈恢复复制普通异常时丢失附加诊断。

## 扩展与权限

`ToolCheckpoints.register` 返回可撤销注册，使用注册实例身份撤销，旧 handle 不能误删同 ID 的新注册。`installCheckpoint` 为注册 ID 添加所有者命名空间，同名扩展可安装到多个会话，回调限定到所属 sessionId，并在作用域销毁时撤销。扩展只允许否决调用和追加结果备注；审批、PLAN 与最终工具策略仍由 ToolExecutor 执行，后置回调不能修改工具成功状态、审批标记或调用身份。

## 验证

假远程后端验证文件/命令处于同一世界、PTY 与协议子进程使用后端自身能力、下载写入远端路径、脱敏后完整输出保存在同一环境、恢复及撤销不触及本地工作区。还覆盖下载缺少完成确认/校验确认、产物枚举及淘汰失败、取消传播和下载排空后再关闭环境。生命周期测试覆盖获取资源与关闭的竞态、扩展创建回滚、清理失败重试、父子进程隔离、MCP 连接复用/卸载和注册撤销。测试不调用真实模型 API 或 SSH 服务。

终端生命周期使用假进程、假环境和内存记录库验证取消后迟到返回、创建失败回滚、分步清理重试、批量关闭失败、并发关闭和创建任务自关闭保护；这些测试不启动原生 PTY，设备上的终端渲染仍需单独验证。
